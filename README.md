# 导师探索 · 在线审阅版

日期：2026-11-12，台北时间。

**在线入口：[打开可操作审阅版](https://zlgao2004-leon.github.io/mentor-explorer-review/)**。访问无需登录，也不依赖项目主机在线。

帮助学生从已有课程或项目经历出发，发现直接对口和机制、方法相邻的导师，理解哪里能衔接、哪里需要转向，并完成论文核读、联系准备与跟进。

这是可操作的审阅演示，不是已开放的学生服务。页面只加载两个预跑的虚构背景：3D NAND 电荷俘获、2.4 GHz 功放转毫米波。每个示例保留22位已有模型复核记录的导师，普通档位首批5位，会员演示最多4批；不涉及收费或账号鉴权。

## 可以操作

页面分成五个工作区：背景、探索、跟进、联系信、合作论文。桌面探索页为“方向／名单／详情”三栏；窄屏用底部导航，导师详情在名单中展开。共同论文改为按实际篇数排列的条形名单。

2026-11-12 界面与首批规则更新：NAND 首批为丁士进、任堃、唐克超、王润声、张卫；毫米波首批为张勇、方中元、池保勇、舒一洋、康凯。对象和问题都不一致的老师不占首批；研究依据重叠的紧密共同作者错开批次；直接对口者足够时首批保留一个邻近席位。相关导师仍可从共同论文入口查看，不能据此断言同一课题组。

这次使用原有判断重排，没有重新运行模型，也没有改写模型的推荐理由。界面更新不代表匹配准确度得到新的验证。

- 选择示例，查看方向地图，选择方向并探索后续五人批次。
- 查看推荐连接、迁移差别、提问建议、论文题录、完整作者列表、已有简介与原摘要。
- 查询某位老师为何未出现在此示例；区别目录缺失、学校范围、未召回、未推荐与尚未复核。
- 收藏老师、记录发信和回复日期、备注、设置跟进提醒，刷新后保留。
- 编辑日程、查看月历、导出带台北时间提醒的ICS文件。
- 用虚构简历体验PDF/DOCX文字提取；文件仅在浏览器内解析，不上传。
- 用模板准备联系信，选填已经保存的论文题名和问题，编辑后导出TXT、DOCX、EML。
- 查看真实的已确认共同论文网络和方向间共同论文；可切换到已打包的一层邻居。

## 明确未开放

## 阅读结果时的边界

页面秒开来自预先运行，不证明新输入达到2分钟目标；上一轮三次新输入实测中位数约130秒，尚未达标。完整预跑初判的有连接导师分别为53位、50位，此分享版仅开放各22位已有模型复核记录的卡片，后续批次不会临时调用模型。原先E01点名25人的召回仍有漏人问题，未在本次发布中修复。

模型复核不等于领域专家人工验收。研究判断主要依据题名、摘要和官网方向，未逐篇读出版社全文。数字待核的定量结论不作为推荐依据；来源原摘要保留供审阅。通讯作者为数据库标注，未经出版社核对。共同署名不能证明师生关系、同一课题组或当前仍有合作。

未重新运行全库标签、匹配判断或收费API。发布范围只有示例所需资料、公共目录姓名学校与精选合作论文关系；不含API密钥、邮箱授权码、原始简历、私有运行日志、完整论文库或运行后台。
